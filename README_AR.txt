NEXORA — النسخة التجريبية للغرف الصوتية

ما الذي تحتويه؟
- دخول باسم فقط، بدون إنشاء حساب.
- إنشاء غرفة ورابط دعوة.
- صوت مباشر بين أعضاء الغرفة (حتى 8 في هذه النسخة).
- دردشة كتابية.
- كتم المايك ومغادرة الغرفة.

مهم جداً:
هذه ملفات المشروع وليست رابطاً منشوراً على الإنترنت بعد. لكي يعمل الصوت بين هاتفين، يجب نشر الخادم على خدمة استضافة تدعم Node.js وتفعيل HTTPS. المتصفح لا يسمح بالمايك على رابط عادي غير آمن، باستثناء localhost.
هذه النسخة تستخدم خادم STUN مجاني للتجربة؛ بعض شبكات الهاتف أو الواي فاي قد تحتاج TURN relay مدفوع/مهيأ كي يتصل الصوت دائماً. لا تعتبرها خدمة إنتاجية أو مضمونة الاتصال بعد.

طريقة النشر المختصرة:
1) ارفع مجلد المشروع إلى مستودع GitHub.
2) أنشئ Web Service على Render واربط المستودع.
3) Build Command: npm install
4) Start Command: npm start
5) بعد النشر افتح رابط HTTPS الناتج واسمح باستخدام المايك.
6) أنشئ غرفة وانسخ رابط الدعوة وأرسله لصديقك.

لا تضع كلمات مرور أو مفاتيح سرية داخل ملفات الواجهة.
